# AI-Powered Multiple Choice Question Generator and Assessment System

QuizNova AI is a simple AI-powered quiz application built using Python, Streamlit, and Hugging Face Inference API. It generates multiple-choice questions based on the user's selected topic and difficulty level, then evaluates the user's answers and displays the final score with explanations.

## Features
AI-powered MCQ generation
Enter any topic
Generate 5–10 questions
Easy, Medium and Hard difficulty levels
Four options for every question
Automatic answer evaluation
Displays the correct answer for wrong responses
Provides a short explanation for each question
Displays final score
Create a new quiz easily
Uses Hugging Face Inference API for faster generation

## Technologies Used
Python
